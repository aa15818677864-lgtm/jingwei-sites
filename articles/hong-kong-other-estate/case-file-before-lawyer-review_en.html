Prepare a cross-border estate file that a Mainland lawyer can assess immediately

The most useful file is not a bulk photo dump. It has a one-page brief, people map, asset schedule, chronology and a small set of clearly named originals.

Start with the actual decision

Every item should state what it is, where it came from, who holds the original and what question it may answer.
