Singapore Passport Name vs Mainland Chinese Records: How to Connect Them

Start with three existing records. Do not treat every English-Chinese name difference as a formal name change.

Last updated: 2026-07-25

Put three records on the table

  • The current passport or identity document
  • The earliest Mainland record showing the Chinese name
  • An older record matching a birth date or identity number

First decide whether the spelling changed or the person changed their name

If the date of birth, identity number or parents' names match and the difference is limited to Chinese characters, romanisation or dialect spelling, organise the records as different versions of the same name. If the name changed after marriage or a formal procedure, build a dated chain from the old name through the change document to the new name.

Similar pronunciation and family recollection are not enough. The most useful evidence is a dated record with an identifying number that places both names in one person's history.

1. Start with the current identity document

Copy the full name, identity number and validity date from the current passport. If it already shows a new name, find the previous passport or pre-change identity record. Do not force a simple English-Chinese spelling difference into a formal name-change process.

2. Build a three-column name table

Use the document date in the first column, the name exactly as printed in the second, and the document title and number in the third. Put the birth record, old passport, marriage paper, current passport and old Mainland record in date order. The missing link usually becomes visible.

3. Look for the record that explains the change

Ten bills showing the same English name are less useful than a birth record, earlier passport, marriage certificate, deed poll, or record carrying two name versions with one identity number. A deed poll is a formal name-change instrument; it is relevant only where a real name change occurred.

If the Chinese name appears only in an old Mainland record, note when that record was created, which identity document was used and whether the address, date of birth or identity number can be matched elsewhere.

4. Translation and an apostille do not prove the identity link

A translation should keep every name, date and number consistent. An apostille authenticates the signature, official capacity or seal on a public document. Neither process invents the missing evidence that two names belong to one person. Show the name table and two or three core records to the Mainland receiving side before preparing the whole file.
