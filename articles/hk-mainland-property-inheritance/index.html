文章 / 香港繼承 / 內地房產

香港居民繼承內地房產過户，先確認繼承權，再辦理不動產登記

香港居民、港人家庭或人在香港的繼承人，遇到深圳、廣州、珠海、佛山、上海、北京等內地房產繼承問題時，關鍵不是把事項當作普通過户處理，而是先確認繼承權、繼承人範圍和香港文件能否按內地要求使用，再進入不動產轉移登記。

發佈：2026-05-21 · 更新：2026-07-02 · 約 6 分鐘閲讀

文章要點

  • 房產在內地，通常先看不動產所在地的繼承和登記要求。
  • 香港形成的死亡證明、親屬關係、聲明和授權文件，往往要先處理公證轉遞。
  • 有遺囑、繼承人不一致、房屋有按揭或查封，辦理路徑和週期會明顯變化。

先看結論

這類事項通常不是“拿着香港文件直接去過户”。更穩妥的順序是：先確認繼承權和繼承人範圍，再核對香港文件能否按內地機關要求使用，最後才進入不動產轉移登記。繼承人之間有爭議、有人失聯、房屋有按揭抵押或產權狀態不清時，還需要先補強證據或先解決前置問題。

你先確認這 4 件事

先把事實框架理順，後面判斷材料、週期、費用和是否需要法院路徑，都會快很多。

1. 房產在哪裏

確認房產所在地、登記權利人、是否已有房產證或不動產權證。

2. 被繼承人情況

確認去世時間、地點，以及死亡證明、身份文件來自哪裏。

3. 繼承人和遺囑

看是否有遺囑、全部繼承人能否一致、是否有人放棄或反對。

4. 房屋現狀

看是否存在按揭、抵押、查封、未辦證、共有或登記錯誤等問題。

可直接複製給律師的事實整理格式

房產在【城市】，登記在【姓名】名下；被繼承人於【時間 / 地點】去世；現有繼承人為【姓名 / 關係】；目前已有或缺少【遺囑 / 死亡證明 / 親屬關係證明 / 授權文件】；房屋存在或不存在【按揭 / 抵押 / 查封 / 未辦證】。

  • 如果人在香港，最好同時説明是否方便來內地、是否希望遠程委託辦理。
  • 如果已有香港文件，説明文件類型和是否已經辦過公證轉遞手續。
  • 如果繼承人之間意見不一致，先寫清楚爭議點是誰和什麼問題。
  • 如果只想先估週期或費用，也要先把房產城市和繼承人情況説明白。

為什麼不能直接當作普通過户

內地房產屬於不動產。涉及法定繼承時，通常要先看不動產所在地的繼承和登記規則；香港本地遺產承辦程序和內地不動產登記程序不是一回事。即使香港方面已經形成相關文件，也要看這些文件能否按內地機關要求使用。

所以初步判斷時，比較穩妥的做法，是先把問題拆成兩層：第一層是繼承權如何確認，第二層是確認後怎樣向房產所在地的不動產登記機構辦理轉移登記。

香港文件用於內地，通常要看公證轉遞

香港形成的死亡證明、親屬關係證明、聲明書、授權委託書等，不能簡單理解為“直接拿到內地就能用”。實務中通常要先區分文件類型，再看是否需要辦理相應的公證、審核及加章轉遞手續後供內地使用。

如果繼承人希望人在香港完成授權，再由內地律師協助辦理，也要先看房產所在地登記機構、公證機構對委託文件和身份文件的具體要求。

有遺囑、無遺囑、繼承人不一致，路徑不同

有遺囑時，要看遺囑形式、簽署時間、處分範圍以及是否有其他繼承人提出異議。無遺囑時，通常要先梳理法定繼承人範圍和順序，再看全部繼承人能否就分配比例和過户安排達成一致。

如果繼承人之間不同意、有人失聯或不配合，往往不能按簡單登記路徑推進，可能需要先補強證據、協調分配安排，必要時再通過法院確認繼承或遺產分割。

這些情況要先查產權狀態

  • 房屋仍未辦證，或開發商、登記歷史還沒完全理順。
  • 房屋存在按揭、抵押、查封或其他權利負擔。
  • 房屋屬於共有財產，或登記信息、面積、姓名不一致。
  • 房屋已被佔用、出租，或與遺產分配安排存在其他衝突。

税費、週期和費用怎麼判斷

法定繼承人通過繼承承受土地、房屋權屬，通常有契税免徵規則；但登記費、材料費、公證或訴訟路徑成本、香港文件公證轉遞費用以及律師協助費用，需要結合城市、材料完整度、繼承人人數和爭議情況判斷。

因此，客户如果只問“多少錢、多久能辦好”，還需要補充房產所在地、繼承人情況、遺囑和材料狀態，才能進一步判斷。

可以先用 AI 初步梳理

如果還不確定自己的情況屬於哪一類，可以先進入 AI 法律初步問答。建議直接説明：房子在哪個城市、登記在誰名下、誰去世了、有沒有遺囑、繼承人是否一致、香港文件是否已經準備好。AI 的作用，是先把問題拆清楚，再把你引到更合適的專題入口。

常見問題

香港居民繼承內地房產，是按香港法律還是內地法律處理？

涉及內地不動產時，通常要先看不動產所在地的繼承和登記規則。香港本地遺產程序不能直接替代內地不動產過户手續。

香港死亡證明或親屬關係證明能直接拿到內地用嗎？

一般不能簡單判斷為直接使用。要看文件類型、形成地點和內地使用要求，通常涉及公證及加章轉遞手續。

繼承人不同意還能過户嗎？

如果繼承人之間有爭議、有人失聯或不配合，可能需要先處理繼承權確認或遺產分割問題，再看能否辦理登記。

法定繼承人繼承內地房產要交契税嗎？

法定繼承人通過繼承承受土地、房屋權屬通常有契税免徵規則。其他費用和地方材料要求仍要結合房產所在地判斷。

快速判斷

  • 房產是否在中國內地，且知道具體城市。
  • 是否已經確認全部繼承人和有無遺囑。
  • 香港文件是否已經準備，是否需要公證轉遞。
  • 房屋是否有按揭、抵押、查封或未辦證問題。
