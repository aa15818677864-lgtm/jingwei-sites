文章 / 香港繼承 / 銀行存款與保險

親人在內地留下銀行存款、理財或保險，香港家屬先怎麼查

很多香港家屬一開始並不是想打官司，只是想知道：親人在內地到底有沒有賬户，銀行肯不肯查，金額不大能不能簡化處理，以及如果卡、手機或保單已經在別人手裏，自己還能不能把事情弄清楚。

最後更新：2026-07-23

先抓住三點

  • 先別急着問“能不能拿錢”，先把賬户線索、親屬關係和誰在保管資料講清楚。
  • 5萬元小額簡化提取有幫助，但不是免材料，也不適合拿來套所有銀行產品。
  • 存款、理財、保險、證券要分開看；特別是保單有沒有受益人，結論可能完全不同。

先説最現實的一句

這類事情真正卡住的，往往不是一句“有沒有繼承權”，而是資料能不能接得上：人已經去世，賬户在哪裏不清楚；香港家屬人在外地，銀行又要核身份、核關係、核賬户；如果家裏還有人不配合，或者已經有人拿着手機、銀行卡、保單原件，事情就更不能只按“去銀行取錢”理解。

先把情況分成這四塊

你不用一開始就把法律問題講得很完整。先把下面四塊説清楚，律師或機構才比較容易判斷下一步是先查詢、先補文件，還是先處理家屬之間的爭議。

1. 你手上有什麼線索

銀行卡、存摺、短信提醒、工資流水、銀行 App 截圖、保單、舊回單，哪怕只有一張照片也有價值。

2. 家屬能不能一起配合

配偶、子女、父母之間能不能一起簽字、提供資料，會直接影響能不能走比較省事的方式。

3. 大概是什麼錢

普通存款、理財、保險、證券、國債、債權，處理規則不完全一樣，金額大小也會影響銀行要求。

4. 資料和賬户在誰手裏

如果有人拿着銀行卡、手機、密碼或保單原件，重點就不是單純提取，而是先把事實和軌跡固定下來。

如果要先問律師，可以這樣説

親人於【時間 / 地點】去世；目前家屬包括【姓名 / 關係】；手上有【銀行卡 / 存摺 / 工資流水 / 短信 / 保單 / 理財記錄】；懷疑涉及【銀行存款 / 理財 / 國債 / 保險 / 證券 / 應收款】；現在最麻煩的是【不知道開户行 / 家屬不一致 / 有人已經提取 / 無法登錄手機銀行 / 保單原件在別人手裏】。

  • 如果只知道親人在內地工作過，但不知道具體銀行，先把工作城市、原單位和發薪線索寫清楚。
  • 如果手上有舊銀行卡、短信通知或理財回單，資料不全也先拍照保留，不要先丟掉。
  • 如果已經有人拿着卡、手機、密碼或保單原件，先寫清楚是誰在保管、什麼時候開始保管。
  • 如果你人在香港，希望遠程推進，也要一開始説明自己能否配合辦理授權文件。

第一步通常不是取錢，而是把錢在哪裏查清楚

很多家屬最焦慮的不是“最後怎麼分”，而是連親人在內地有沒有賬户、在哪家銀行、買沒買理財或保險都不清楚。比較有用的線索，通常包括銀行卡、存摺、工資卡、手機銀行截圖、短信提醒、舊轉賬記錄、理財回單、保險保單、原單位信息、常用開户地址，以及手機裏留下的交易提醒。

如果現在只能判斷“大概有錢在內地”，但還不能指向具體銀行或保險公司，就不要急着問“能不能馬上提”。這一步更實際的問題是：現有線索能不能支撐查詢？如果不能，是先補身份關係材料、委託文件，還是先做繼承關係確認。

金額不大，也不等於拿着死亡證明就能領

已故存款人小額存款簡化提取規則，把賬户限額統一提高到5萬元，並把黃金積存、國債、部分理財產品等納入規則範圍。對一些家庭來説，這確實能少走一段程序。

但“簡化”不是“免審”。銀行仍會看申請人是不是合適的辦理人，賬户是否落在規則範圍內，同一法人機構下的賬户餘額如何合併計算，材料是否齊全，以及是否存在繼承人爭議、代持、凍結或異常交易。

存款、理財和保險，不能混在一起問

普通銀行存款和部分理財產品，可能有簡化提取的空間；保險要先看合同裏有沒有指定受益人；證券和基金則通常還要看券商賬户、持倉、分紅和過户要求。所以家屬問“能不能一起辦”，比較負責任的回答通常是：先拆開看。

尤其是人身保險，如果已經明確指定受益人，保險金一般先按保險合同處理；只有沒有指定受益人、受益安排失效，或者出現其他法定情形，才可能進入遺產繼承處理。

遇到這些情況，先不要只想着走簡化

  • 繼承人分散在香港、內地或海外，有人失聯、反對，或者不願意配合簽字。
  • 只知道“內地可能有錢”，但不知道具體銀行、保險公司或產品名稱。
  • 懷疑有人在親人去世前後取款、轉賬、改綁手機銀行，或者實際控制賬户。
  • 除了存款，還涉及證券、保險、債權、代持、共同出資等問題。
  • 銀行或機構要求補公證書、法院文書、授權文件，或者提出其他審查要求。

如果懷疑有人已經提取、轉移或控制款項

這類情況在家屬之間並不少見。有人拿着銀行卡、手機、短信驗證碼、保單原件，或者在親人去世前後一直代為操作賬户，其他家屬自然會擔心錢是不是已經被轉走。這個時候，處理重點就不只是“怎麼領錢”，而是先看有沒有交易軌跡、有沒有授權或代持解釋、現有線索能不能固定下來。

監管規則中有關於第一順序繼承人申請查詢已故存款人死亡後以及死亡前 6 個月內賬户交易明細的安排，但能不能調取、調取到什麼程度，還要看申請人身份、銀行審核和具體賬户情況。已經出現明顯爭議或資金異常時，更適合先做法律風險評估，不建議自己逐家機構反覆試。

如果你還沒法判斷，先把問題説成這樣

親人可能在哪個城市有銀行賬户或保險？你手上已經有什麼線索？繼承人之間能不能配合？有沒有人已經掌握銀行卡、手機、保單或提款線索？把這些先説清楚，通常比直接問“要不要公證、多久能拿到錢”更容易得到有用的判斷。

如果你的問題還牽連到這些事

香港居民繼承內地房產過户總覽 香港死亡證明、親屬關係證明能否用於內地繼承 繼承人不配合或有爭議怎麼辦 税費、週期和費用怎麼判斷

常見問題

只知道親人在內地可能有存款，但不知道在哪家銀行，先做什麼？

先別急着逐家銀行問。把銀行卡、存摺、短信提醒、工資流水、舊回單、手機銀行截圖、原單位和常用開户地址整理出來，再看這些線索能不能指向具體機構。

金額在5萬元以內，是不是一定可以直接取？

不一定。簡化提取規則能讓一些個案少走程序，但銀行仍會審核申請人身份、繼承人範圍、賬户餘額、產品類型和是否存在爭議，不能理解成拿死亡證明就能直接領錢。

保單有受益人時，還屬於遺產嗎？

通常先看保險合同。如果人身保險已經明確指定受益人，保險金一般先按合同安排處理；只有沒有指定受益人、受益安排失效或出現其他法定情形時，才可能進入遺產繼承處理。

懷疑有人已經把錢取走了，還能處理嗎？

可以先把銀行卡、手機、短信、轉賬記錄、保單原件由誰保管等情況固定下來，再判斷是否能申請交易明細、核對授權或代領説法，以及是否需要通過協商或訴訟追索。

你現在卡在哪

  • 完全不知道錢在哪，只剩一些舊短信、銀行卡或工資線索。
  • 知道賬户或保單，但銀行、保險公司不肯直接辦理。
  • 家屬之間不一致，或者有人拿着卡、手機、密碼、保單。
  • 存款、理財、保險混在一起，不知道該按哪一類處理。
