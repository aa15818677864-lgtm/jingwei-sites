# 关键词与同行研究数据库

更新日期：2026-10-23。现有 226 个关键词、90 个变体、170 条文章索引。

今天完成20个关键词的内置浏览器研究，查看Google前两页自然结果，阅读相关正文，再核对官方资料。对应20篇独立文章及60个语言页面已核验上线。今日记录保留查询、来源、业务分类、改写重点和发布地址，不填写未经确认的排名。早期SERP记录保留供追溯，并标记为今日未复核。

## 文件与使用

- `seo_keyword_research.sqlite`：完整数据库。
- `keywords.csv`：词库，包含已研究和待搜索状态。
- `daily-story-research.csv`：今日20词、来源与发布记录。
- `business-category-volume-summary.csv`：按业务类别和目标地区汇总搜索量状态。
- `daily_search_tasks.csv`：搜索任务。新增100个香港受众候选词，排入10月24日至28日，每日20词，尚未搜索。
- `keyword-seed-pool-20261023.json`：新增100词的可重放来源，不代表已验证搜索需求。

## 平台分工

Google Search是主要研究平台。使用短词并带“内地”，只看前两页自然结果，不点击付费广告；记录搜索环境，避免把其他地区结果说成香港排名。打开实际相关文章，提取用户问题，独立撰写并复核。

Google Ads Keyword Planner用于补月均搜索量，须同时记录地区、语言、网络及月份。Search Console反映本网站展示与点击；Google Trends是相对热度，两者均不能代替市场月搜索量。Bing、YouTube、知乎、微信等可补充问题表达与内容角度，其平台排名不等于Google排名。

## 搜索量与业务边界

本轮没有取得可核验的月均搜索量，数值保留NULL，分类汇总显示未测得，不能当作零搜索量，也不能据词长宣称高流量。后续有真实数据时再按来源和观察期间补入。

团队在深圳执业，只处理中国内地法律事务；香港是主要受众，海外是读者所在地。商标、专利等知识产权选题不进入本轮生产。候选词须先完成浏览器研究，才能登记已研究；草稿不能算上线文章。

## 维护

日常增量更新运行 `python tools/update_daily_keyword_database.py`。基础重建脚本在覆盖前保留数据库备份，并重放今日研究与候选词来源。更新后检查SQLite完整性和外键；发布状态只能在逐页线上核验成功后写入。
